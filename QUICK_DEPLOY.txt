STEP 1: CREATE GITHUB REPOSITORY
─────────────────────────────────────────────────────────────────────
1. Go to: https://github.com/dayyalabhanuprakash?tab=repositories
2. Click "New" button
3. Repository name: resume-tailor
4. Keep it Public
5. Don't initialize with README
6. Click "Create repository"


STEP 2: PUSH CODE (Copy these commands)
─────────────────────────────────────────────────────────────────────
cd resume-tailor-app
git init
git add .
git commit -m "Bhanu's Resume Tailor - Production Ready"
git branch -M main
git remote add origin https://github.com/dayyalabhanuprakash/resume-tailor.git
git push -u origin main


STEP 3: DEPLOY ON RENDER
─────────────────────────────────────────────────────────────────────
1. Visit: https://dashboard.render.com/
2. Sign in with GitHub
3. Click "New +" → Select "Web Service"
4. Click "Connect GitHub" → Select "resume-tailor" repo
5. Fill in these settings:

   Name: bhanu-resume-tailor
   
   Environment: Python 3
   
   Build Command (copy this):
   pip install -r requirements.txt && python -m nltk.downloader punkt stopwords punkt_tab
   
   Start Command (copy this):
   gunicorn app:app
   
   Plan: Free

6. Click "Create Web Service"
7. Wait 2-3 minutes for deployment
8. DONE! 🎉

WHAT IT DOES:
─────────────────────────────────────────────────────────────────────
1. User uploads resume
2. User pastes job description
3. AI analyzes both documents
4. Calculates ATS compatibility score
5. Shows matched keywords
6. Provides improvement suggestions
7. User downloads optimized resume
