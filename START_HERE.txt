Copy and paste these commands in your terminal:

STEP 3: DEPLOY ON RENDER (2 minutes)
───────────────────────────────────────────────────────────────────────────
→ Visit: https://dashboard.render.com/
→ Click "New +" → "Web Service"
→ Connect your GitHub repo "resume-tailor"
→ Fill in:
  Name: bhanu-resume-tailor
  Build: pip install -r requirements.txt && python -m nltk.downloader punkt stopwords punkt_tab
  Start: gunicorn app:app
→ Click "Create Web Service"
→ Wait 2-3 minutes
→ DONE! 🎉

✨ WHAT YOUR APP DOES:
═══════════════════════════════════════════════════════════════════════════
1. User uploads resume (PDF, DOCX, or LaTeX)
2. User pastes job description
3. AI analyzes and calculates ATS score
4. Shows matched keywords and improvements
5. User downloads optimized resume
